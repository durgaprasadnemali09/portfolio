# Durga Prasad Reddy - Portfolio

Personal portfolio website: Java, Spring Boot, SQL and web development.

## Files
- `index.html` - the whole site (HTML, CSS and a little JavaScript)
- `images/photo.jpg` - profile photo (replace with your own, same name)
- `resume.pdf` - resume used by the "Download my resume" button

## Run locally
Double-click `index.html`, or in VS Code use the Live Server extension.

## Edit
- Search `index.html` for text in `[square brackets]`: those are placeholders.
- Accent colour: replace `#22D3EE` everywhere with another light hex colour.
- Update project links (the "View on GitHub" buttons) to each project's own repo.

## Deploy free on GitHub Pages
1. Push this folder to a GitHub repository.
2. On GitHub: Settings > Pages > Source: "Deploy from a branch" > Branch: `main` and folder `/ (root)` > Save.
3. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.
